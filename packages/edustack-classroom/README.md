# edustack-classroom

GitHub and Classroom automation tools for EduStack.

Provides:
- Announcement generation in Word (.docx) format from course feeder workbooks.
- Automated creation of templates and group repositories on GitHub.
- Automated creation and scheduling of assignments on GitHub Classroom.
- Auto-management (revocation & re-invitation) of pending organization invitations.

## Installation

```bash
pip install -e packages/edustack-classroom
```
